# Third-party notices

Khamsin's engine, design tokens and utility registry are original work. No source code
or data tables were copied from another utility-CSS implementation.

The class *syntax* follows conventions that are widely used and documented publicly
(for example `px-4`, `hover:bg-*`, `md:flex`). Syntax compatibility is not an endorsement
by, or affiliation with, any other project.

## Runtime dependencies

The `Khamsin` package for consumers has no third-party runtime dependencies beyond the
.NET platform.

## Build-time dependencies

- Test and analyzer projects reference Microsoft libraries (MIT); they are not shipped
  in the consumer package.

If third-party data is ever copied into this repository, its notice will be added here.
